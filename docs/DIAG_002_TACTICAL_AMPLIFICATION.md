# DIAG-002：Tactical 乘性放大机制诊断（EXP-DIAG-EPL-002）

> 本实验**只回答一个问题**：事件引擎中 `chance_creation_modifier × attacking_intensity` 的乘性组合是否放大重复信号、从而造成 full_system 性能退化。
> 只读纪律：生产模型、35 条规则、config/default.json、V1.2 数据层、冻结基线 EXP-REAL-EPL-BASE-001（`7c52c6bdfa37`）与 EXP-DIAG-EPL-001 均未修改。本实验在独立诊断沙箱 `backtest_output/diag_002_tactical_amp/` 内完成。
> 不优化参数、不寻找最佳系数：加性臂使用与乘性臂中性点/一阶等价的原样尺度`cc + f_att − 1`，未做任何调参。

## 1. 实验设计

三个臂在**完全相同**的数据（2025-26 EPL）、样本（`range(0,380,3)[:120]`，120 场）、seed（20240101）、模拟次数（400）与 walk-forward 设置下比较，其余 Agent 完全不变。差异仅发生在事件引擎 `_attack_intensity` 的两个战术因子处：

| 臂 | 定义 | 引擎融合点行为 |
| --- | --- | --- |
| A_mult | 生产乘性结构：`lam *= cc * f_att` | 生产原样（逐分钟 `lam *= cc` 后再 `lam *= f_att`） |
| B_off | 战术机会创造通道关闭：引擎融合点强制 `cc=1.0`（f_att 动态不变） | 只关闭 cc 通道；f_att 的赛中动态（比分/红牌规则）保留 |
| C_add | 加性结构：`lam *= (cc + f_att - 1)`，组合因子裁剪至 [0.1, 3.0] | cc 与 f_att 以加法组合成单一因子，再乘入 |

其中 `cc = tac.chance_creation_modifier`（TacticalMatchupAgent 输出，经 Opening 层写入世界状态），`f_att = 0.55 + 0.9 × tac.attacking_intensity`。

**尺度等价性论证（不调参）**：A 的因子为 `cc×f_att`，C 为 `cc+f_att−1`。两者在**中性点（cc=1, f_att=1）精确相等**（均为 1），且一阶 Taylor 等价：令 cc=1+a、f_att=1+b，则 A=1+a+b+ab、C=1+a+b。二者之差就是二阶交叉项 `ab`——**这正是被检验的『乘性组合』机制本身**，不是尺度混杂，因此不标记 SCALE_CONFOUND。C 的组合因子裁剪到 cc 的定义域 [0.1, 3.0]；本实验统计了裁剪被触发的次数（见第 3 节），若裁剪频繁发生，解释时会计入该人为因素。

**实现方式**：仅在运行期内对 `director.EventTriggerAgent` 的类引用做**monkey-patch**（子类先改写两个战术因子、再调用**未改动**的生产 `_attack_intensity`，最后逐字段还原世界状态）。生产源码零修改；A_mult 臂直接原样委托生产代码。

**与配置级消融 `full_minus_tactical` 的区别**：B_off 只在引擎融合点关掉 cc；而 EXP-DIAG-EPL-001 的 `full_minus_tactical` 还同时中立化了 Opening 开场通道（开场因子含 0.45×(cc−1) 项）。因此 B_off 与其接近但**不应完全相等**。

### 1.1 忠实性验证（沙箱 vs 冻结缓存）

- A_mult vs 冻结 `full`（同 seed/样本/400 模拟）：最大绝对差 home_win=0、draw=0、away_win=0、expected_goals=0 → **完全一致（沙箱忠实）**
- B_off vs 冻结 `full_minus_tactical`：最大绝对差 home_win=0.0600、draw=0.0475、away_win=0.0625、expected_goals=0.190 → 差异来源为 Opening 开场通道（预期之内，非沙箱缺陷）。

## 5. 五个分析问题

**1. 乘性结构是否扩大方差？**

场均战术因子 std（主队侧）：A=0.1133、B=0.1557、C=0.1527；A/C 比值 0.74。逐分钟 lam std（主队侧）：A=0.0223、B=0.0367、C=0.0269。
→ **否（方向相反）**：乘性结构的因子方差反而比加性结构小 26%。原因：本数据中 cc 均值远小于 1（A 臂因子均值 0.60），乘积 cc×f_att 把 f_att 的赛中波动整体压缩 —— 乘性在此充当**衰减器**而非放大器。『乘性放大方差』的方向性假设在本数据上被否定。

**2. 是否产生极端概率？**

分钟级高强度（lam≥0.4，主队侧）：A=0.000%、C=0.000%；1X2 高置信场次（max≥0.65）：A=0、C=0。
→ 高置信 1X2 场次在 A/C 间相同；极端概率的臂间差异不体现在计数上。

**3. 是否放大 Team/Tactical 的重复信息？**

Team 重复信号 → 战术因子差的相关：A=+0.8587、B=-0.5820、C=+0.8230；Team 信号 → home_win 的相关：A=+0.7284、C=+0.7408；回归斜率：A=0.302、C=0.263。
→ **部分支持**：Team 信号→战术因子差的相关 A（+0.8587）> C（+0.8230），home_win 对 Team 信号的斜率 A（0.302）> C（0.263）——乘性结构把重复信号向战术因子的传导放大；但 home_win 的相关 C（+0.7408）略高于 A（+0.7284），『因子→最终概率』环节的证据不一。

**4. additive 是否降低误差传播？**

最终 home_win 概率的跨场 std：A=0.0314、B=0.0219、C=0.0269；expected_goals 跨场 std：A=0.2793、B=0.0922、C=0.2623。
→ 输出离散度：是（home_win 与 expected_goals 的跨场 std 在 C 中均更小）。但信号传导证据不一：home_win 与 Team 信号的相关 C（+0.7408）反而略高于 A（+0.7284），回归斜率则 C（0.263）< A（0.302）。→ 结论：**additive 降低输出离散度的方向一致，但『降低误差传播』只得到部分支持（弱证据）。**

**5. 性能变化是否足以支持『乘性放大是根因』？**

Brier：A=0.6677、B=0.6646、C=0.6694。A−C 配对差均值 -0.00171（t=-0.41），A−B 配对差均值 +0.00316（t=0.25）。判定阈值 0.002（与 EXP-DIAG-EPL-001 一致）。

## 6. 结论（严格按证据强度措辞）

- 对『乘性放大』假设的判定（A vs C）：**乘性放大尚未被证明是主要根因**：加性臂 C 并未优于乘性臂 A（配对差 -0.00171，t=-0.41）。假设保持开放，不因 DIAG-001 的相关性证据而预判。
- Tactical 通道整体（B vs A）：关闭 cc 通道后 Brier 变化 +0.00316（t=0.25），方向与 380 场消融（改善 0.0044）一致但远未达统计显著 → 通道净效应在本样本不显著，不作归因。

**PRIMARY（证据强）：**
- （无 —— 未发现达到证据强度阈值的结论）
**SECONDARY（证据中等）：**
- 乘性组合在本数据中充当**强度衰减器**：cc 均值远小于 1 使 A 臂因子均值 ≈0.60，乘积压缩 f_att 波动（A 因子 std 0.1133 < C 0.1527）——『乘性放大方差』的方向性机制与实测相反
- cc 通道同时承载『强度阻尼』与『信息贡献』：B_off 关闭后 expected_goals 全部 ≥3.0（阻尼解除），其 Brier 变化不能单独归因于信息
**UNCONFIRMED（证据不足，不猜测）：**
- 乘性放大假设未被 DIAG-002 支持（A−C Δ=-0.00171）
- Tactical cc 通道净效应（B−A Δ=+0.00316，t=0.25）不显著；且 B_off 同时大幅抬高 expected_goals（120/120 场 ≥3.0），提示 cc 通道在本数据中主要起强度阻尼作用
