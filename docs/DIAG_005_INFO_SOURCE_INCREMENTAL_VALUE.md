## 1. 方法与预注册符合性

- 基线：冻结 Elo 概率（380 场，确定性；Brier 0.6310）。
- 探针：`(Elo 概率动态三分位 × 源特征动态中位数)` 展开窗口经验条件频率；回退链（预注册）：(elo×s) 计数 < 20 → elo 分层计数 < 20 → 原 Elo 概率。最小历史 30 场。
- 主检验：ΔBrier（探针 − Elo，三类 Brier）；置换检验 seed 20240101、10000 次。
- **置换实现说明（如实披露）**：主置换把**源特征值**在 380 场间重排（实现预注册的 H0『该源无 Elo 外增量』）；设计文档字面上的『实际结果向量重排』作为次级置换一并报告（DIAG-004 S1 已证明该变体anti-conservative，仅作透明参考）。
- 多重比较：Bonferroni α = 0.0071（7 个设计候选）。
- split-half：前/后 190 场 ΔBrier 均 < 0 才一致。

## 3. 逐源解读（按预注册假设；不超解释）

### 射门质量（主客射正率差，10 场 walk-forward）

- ΔBrier +0.0120（阈值 −0.003），置换 p=0.8510（α=0.0071），split-half 不一致（+0.0058/+0.0183），Murphy C=-0.0000 → **INSUFFICIENT EVIDENCE**。

### 射正率（主客 SOT 绝对量差，10 场 walk-forward）

- ΔBrier +0.0111（阈值 −0.003），置换 p=0.3633（α=0.0071），split-half 不一致（+0.0029/+0.0194），Murphy C=-0.0006 → **INSUFFICIENT EVIDENCE**。

### 赛程密度（主客 congestion_14d 差）

- ΔBrier +0.0091（阈值 −0.003），置换 p=0.0576（α=0.0071），split-half 不一致（-0.0004/+0.0185），Murphy C=-0.0035 → **INSUFFICIENT EVIDENCE**。

### 时变主场因素（截至 t−1 的联盟主场胜率）

- ΔBrier +0.0090（阈值 −0.003），置换 p=0.2015（α=0.0071），split-half 不一致（+0.0115/+0.0064），Murphy C=-0.0014 → **INSUFFICIENT EVIDENCE**。

（C<0 表示探针相对 Elo 的偏离朝实际结果方向；C≈0 表示无独立信号；C>0 表示反信息——与 DIAG-004 的 Agent 偏离同向。四源 C 全部 ≈0（−0.0000/−0.0006/−0.0035/−0.0014），而 ΔBrier 全部为正——探针的估计噪声主导了整体 Brier，无源表现出可与噪声区分的 Elo 外增量。）

## 5. 下一步应该寻找什么信息（而不是增加什么 Agent）

按 DIAG-001~005 累积证据（信息重复 → 乘性放大不成立 → 融合结构非瓶颈 → Agent 无 Elo 外信息 → 现有可测信息源无 Elo 外增量）：

1. **当前数据层内无可测出增量的信息源**：射门质量、射正率、赛程密度、时变主场因子四源全部 INSUFFICIENT EVIDENCE —— 不再投入时间在这些字段上做特征工程。
2. **需要获取的新数据（获取优先级，非 Agent 工作）**：
   - 供应商级**真实 xG/xGA**（含生成时间戳，须 < kickoff）——当前射门统计只是其粗糙代理；
   - **首发阵容与伤停**（含公布时间戳）——DIAG-004 的三型分类因 DATA_UNAVAILABLE 无法真值判定，这是唯一尚未被测试的『信息缺失型』真值源；
   - **跨赛季数据**（第二赛季）——本设计所有探针都只在本赛季内 walk-forward，跨赛季信号不可测。
3. **纪律排除项**：市场赔率（closing_odds 已在数据层，等解除 no-market 约束后可作为最强『人类集成信息』探针，另行设计）。

**结论方向**：在不获取新数据的前提下，不存在已知的 Elo 外信息源值得进一步挖掘；下一步的信息投资应投向**真实 xG 与伤停/阵容数据的获取与验证**，而不是增加 Agent 或在这些已测字段上继续调参。
