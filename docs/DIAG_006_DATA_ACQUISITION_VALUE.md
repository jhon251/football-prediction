# DIAG-006：数据获取价值评估（Data Acquisition Value Assessment）

> **性质：纯评估报告 —— 无实验执行、无模拟、无模型改动，因此不产生注册条目与运行产物。**
> 目标：回答「哪些新增数据源最可能提供 Elo 外增量信息」，给出下一阶段数据投资优先级。
> 纪律：不修改生产代码与 config；不调整权重；不训练模型；不根据结果反向调整设计；
> 不引入未来信息泄漏；closing_odds 仅作**独立研究分支**，不接入生产预测系统。
> 本文件不包含任何 V1.3 或模型优化方案。

---

## 0. 证据基础（继承 DIAG-001~005，全部为已冻结实测）

| 事实 | 来源 |
| --- | --- |
| Elo 是当前最强预测器（380 场 Brier 0.6310，accuracy 0.4711），优于 full_system 0.6592 | 冻结基线 |
| 三个 Agent 配置均未发现 Elo 外信息；Agent 偏离 Elo 为反信息（Murphy C>0，置换 p=1.0） | DIAG-004 |
| Elo 纠错 Agent 的频次是反向的约 3.9 倍（27 vs 7，p=0.0008） | DIAG-004 |
| 融合结构不是瓶颈（加性探针无改善） | DIAG-003 |
| 当前数据层内四个可测源（射门质量/射正率/赛程密度/时变主场）全部 INSUFFICIENT EVIDENCE（ΔBrier 全为正） | DIAG-005 |
| 三型分类中「信息缺失型」因伤停/阵容 DATA_UNAVAILABLE 无法真值判定 | DIAG-004 |

**推论**：Elo 未被任何现有信息源超越；剩下的候选增量必然来自与 Elo **结构性正交**的信息——
比赛过程质量（xG）、比赛特定人员（阵容/伤停）、以及人类信息集成（市场赔率）。

## 1. 通用验证协议（任何新数据源落地后统一适用，继承 DIAG-005）

- 探针：冻结 Elo 概率之上，`(Elo 概率动态三分位 × 新源分箱)` 展开窗口条件频率；
- 判据（预注册，不得挪动）：`ΔBrier(probe − elo) ≤ −0.003` 且 置换 p < 0.0071
  （Bonferroni）且 split-half 一致 → 才标记「具备 Elo 外增量」；否则 INSUFFICIENT EVIDENCE。
- 泄漏门槛（硬性）：每一条记录必须有**生成/公布时间戳 < kickoff**；赛后更新数据一律
  按赛后版本隔离，不得混入预测输入。
- 效力说明：单赛季 380 场对 ≤0.003 的增量效力不足——这是跨赛季数据（源 4）作为
  「验证使能者」优先级提升的直接原因。

## 2. 数据源逐一评估

### 2.1 真实 xG/xGA（供应商级 expected goals）—— 评级：**HIGH**

- **为什么可能超过 Elo**：Elo 只消费结果（胜/平/负）且更新有滞后；xG 度量**过程质量**
  （每次射门的机会价值）。经典机制：Elo 高估「超额完成 xG」的队、低估「低于 xG」的队，
  xG 差是 Elo 外最著名的预测信号之一。DIAG-005 已证明射门量/射正率等**粗代理无增量**——
  这恰恰说明只有**真实 xG**（含射门位置、部位、机会类型）才有测试价值，代理不能替代。
- **当前缺失原因**：数据层无任何 xG 字段（仅有 shots/SOT 统计）。
- **获取成本**：**中**。免费档：Understat（EPL 全量）、FBref/StatsPerform 页面级；
  付费档：StatsBomb（含逐事件）、Opta/Wyscout（机构级，贵）。参考
  [Where to Find Football Data](https://www.liamhenshaw.com/writing/where-to-find-football-data)、
  [Best European Football Data Providers](https://footballanalytics.ai/european-football-technology/best-european-football-data-providers)。
- **验证难度**：**中**。核心风险是时间戳：多数公开 xG 由模型事后生成/更新，须取得
  「赛前快照版」并核对 < kickoff；否则按泄漏源处理（与用户纪律一致）。
- **投资优先级：第 1 位。**

### 2.2 首发阵容数据 —— 评级：**HIGH**

- **为什么可能超过 Elo**：Elo 是俱乐部级、结果驱动的；首发是**比赛级、人员级**信息。
  关键球员缺阵（如核心前锋/门将）直接改变一场比赛的概率，而 Elo 对此完全不可见——
  这是与 Elo **结构性正交**的最强候选。可获取性有硬保证：英超自 2024-25 起
  **赛前 75 分钟**统一公布首发（[Premier League lineups now announced 75 minutes before kick-off](https://www.givemesport.com/why-premier-league-team-lineups-are-announced-75-minutes-before-kick-off/)），
  公布时间天然 < kickoff，泄漏门槛可机械校验。
- **当前缺失原因**：数据层 lineup 字段全空（`home_lineup_status=unknown`，
  `lineup_observed_at=None`），未接入任何名单来源。
- **获取成本**：**低-中**。官方/俱乐部渠道（赛前 75 分钟）免费可抓；结构化批量
  （Opta/SportMonks 等）为付费档；一次性采集 + 逐场增量。
- **验证难度**：**中**。难点不在时间戳（规则保证），而在信号稀疏：380 场中
  「明确关键缺阵」场次有限，效力受限；建议与伤停源合并验证（2.3）。
- **投资优先级：第 2 位。**

### 2.3 伤停数据 —— 评级：**MEDIUM**

- **为什么可能超过 Elo**：机制同 2.2，但更尖锐——伤停是「人员缺失」的直接证据，
  且 DIAG-004 三型分类中「信息缺失型」正是因伤停数据缺失而无法真值判定，
  这是诊断链上唯一尚未被测试过的类型。
- **当前缺失原因**：`injuries_known=[]` 全空。
- **获取成本**：**低-中**（发布会/俱乐部伤情报告/伤病跟踪站），但**数据质量成本高**：
  需人工核对「确认伤停」vs「出战存疑」。
- **验证难度**：**高**。用户纪律要求：**严格区分赛前已知与赛后信息、禁止模糊新闻代理**。
  实际操作要求每例伤停带「确认时间戳 + 是否出战 + 是否为关键球员」三重标注；
  否则不纳入探针。样本小、标注贵 → 单源评级 MEDIUM，与 2.2 打包获取验证。
- **投资优先级：第 3 位（与 2.2 同一供应商打包）。**

### 2.4 跨赛季数据（第二赛季及更多）—— 评级：**MEDIUM（验证使能者）**

- **为什么可能超过 Elo**：它本身**不是**预测信号，但它是所有信号的**验证器**：
  单赛季 380 场使 DIAG-003/004/005 的关键检验（t=1.16、置换 p、split-half）全部效力不足；
  第二赛季可让：①任何新源的 ΔBrier 检验效力翻倍；②检测**赛季迁移**
  （升/降级球队、风格漂移、Elo 冷启动）；③区分「真实信号」与「单赛季样本现象」。
- **当前缺失原因**：数据层仅 2025-26 一个赛季。
- **获取成本**：**≈0**（football-data.co.uk 等历史 EPL CSV 免费，与现有 ETL 同源同构；
  新赛季随比赛进行自动积累）。
- **验证难度**：**低**（获取）；**中**（赛季迁移分析需处理球队升降级与特征漂移）。
- **投资优先级：第 4 位，但可立即零成本启动、与其他源并行。**

### 2.5 市场赔率（独立分析分支）—— 评级：**HIGH（仅限独立分支）**

- **为什么可能超过 Elo**：收盘赔率聚合了全部公开信息（阵容、伤停、xG 敏感资金），
  是被广泛验证的最强赛果预测器之一；在 DIAG-001~005 的框架中，它是
  「Elo 外增量理论上限」的天然基准——若未来盈利验证，它是必测对照。
- **当前缺失原因**：**非缺失**——`closing_odds`（Avg 盘、kickoff 时间戳）已存在于数据层；
  缺的是纪律许可（no-market 约束，`market_data=false`）。
- **获取成本**：**≈0**（已在数据层）。
- **验证难度**：**低**（数据已带时间戳）；解释难度**中**（需去水/校准，且只能作
  验证基准，不能作为生产预测输入——本文件再次确认此边界）。
- **投资优先级：独立分支最后启动，且仅在用户明确解除 no-market 约束后。**

## 3. 下一阶段数据投资优先级排序（结论）

| 排序 | 数据源 | 评级 | 理由 |
| --- | --- | --- | --- |
| **1** | 真实 xG/xGA（含赛前时间戳） | HIGH | 最大理论增量 + 当前完全缺失；代理已证无效 |
| **2** | 首发阵容（75 分钟规则） | HIGH | 与 Elo 结构性正交；时间戳有规则保证；低成本 |
| **3** | 伤停（确认时间戳，禁模糊代理） | MEDIUM | 诊断链唯一未测类型；标注贵、样本小，随 2 打包 |
| **4** | 跨赛季数据 | MEDIUM（使能者） | 零成本，立即启动；一切验证的前提 |
| **5** | 市场赔率 | HIGH（独立分支） | 仅作盈利验证基准；等解除 no-market 约束 |

**一句话结论**：在不获取新数据的前提下，DIAG-001~005 已穷尽当前数据层的增量可能
（全部 INSUFFICIENT EVIDENCE）；下一阶段的信息投资应**优先获取真实 xG 与阵容/伤停
（带时间戳）**，同时**零成本积累第二赛季数据**作为验证器——而不是增加 Agent、
修改融合或调整任何现有权重。
